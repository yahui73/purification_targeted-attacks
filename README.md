# Diffusion-based Purification for Hash Retrieval under TA-DCH Attack

This repository contains the code for defending hash-based image retrieval models against adversarial attacks generated by **TA-DCH**.

We propose to use a new diffusion-based purification model to preprocess adversarial images before hash retrieval. The goal is to remove adversarial perturbations from attacked images and recover cleaner image representations, thereby improving the robustness of downstream hash retrieval.

## Project Description

Hash-based image retrieval models are vulnerable to adversarial attacks. In this project, adversarial examples are generated using the **TA-DCH attack model**, and then a diffusion purification module is applied to reduce the attack effect.

The purified images are further used for hash code extraction and retrieval evaluation.

## Main Idea

The overall pipeline is:


Clean Image
    ↓
TA-DCH Attack Model
    ↓
Adversarial Image
    ↓
Diffusion-based Purification Model
    ↓
Purified Image
    ↓
Hash Retrieval Model
    ↓
Retrieval Evaluation
